# User Stories

1. As a UiTM Students, I want to help them to rent a house based on their own preference , so that they can choose the house wisely and not to burden their life during study
2. As a house owner, I want to update property availability status in real-time, so that I stop receiving inquiries for houses that are already fully booked.
3. As a system administrator, I want to verify, edit, or remove housing listings, so that the platform remains secure, accurate, and free from scam or outdated posts.
4. As a non-resident UiTM student, I want to view rental locations on an interactive map relative to UiTM Samarahan Campus 1 and Campus 2, so that I can gauge commute distances and minimize daily travel costs.

**Acceptance Criteria:**
- [ ] Users can see markers on an interactive map showing rental properties relative to Campus 1 and Campus 2.
- [ ] Users can click a marker to view estimated commute distance and time.
