# [Smart Housing Recommendation System For UiTM Students Using Content Based Filtering]

-This project streamlines the tedious off-campus rental search for UiTM students by delivering personalized housing recommendations based on their individual budget, location preferences, and required amenities through content-based filtering.

## Problem statement
-Fragmented & Outdated Search Channels: Non-resident UiTM students rely heavily on Facebook posts and manual direct messaging with property owners to retrieve basic housing information, resulting in outdated listings and repetitive communication.

-Inefficient Process & Information Overload: Inquiring about amenities, prices, and availability on an individual basis creates a time-consuming, disorganized search experience that leads to severe information overload.

-Lack of Automated, Personalized Matching: Current housing discovery methods lack intelligent filtering, driving the need for an automated Content-Based Information Filtering model that ranks accommodation based on student preference vector weights.
